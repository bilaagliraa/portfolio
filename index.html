Latar Belakang & Filosofi Belajar

Sebagai mahasiswa S1 Teknik Informatika di UNESA, saya memiliki visi untuk mengintegrasikan kekuatan logika komputasi sistem dengan sentuhan estetika visual. Ketertarikan saya berakar pada pemahaman cara kerja mesin komputer dari tingkat dasar melalui bahasa pemrograman C++, sekaligus bagaimana produk teknologi tersebut disampaikan kepada manusia melalui antarmuka web yang intuitif.

Bagi saya, rekayasa perangkat lunak tidak hanya tentang baris kode yang berjalan tanpa error, melainkan bagaimana menciptakan solusi yang efisien, mudah diakses, dan memiliki daya tarik visual yang kuat.

Dengan semangat pembelajaran yang konsisten, saya aktif mengeksplorasi algoritma dasar, arsitektur pemrograman terstruktur, serta penerapan media kreatif digital untuk mendukung kebutuhan komunikasi teknologi masa kini.

1. Sistem Rekap Nilai Akademik Mahasiswa (C++ CLI)

Implementasi struktur data dinamis vector dan struct untuk kalkulasi bobot nilai (Tugas 30%, UTS 35%, UAS 35%) serta penentuan konversi grade otomatis.

C++ Core System
// Cuplikan Logika Perhitungan Nilai C++ struct Mahasiswa { string nim, nama; double nilaiTugas, nilaiUTS, nilaiUAS, nilaiAkhir; char grade; }; // Kalkulasi Bobot: 30% Tugas, 35% UTS, 35% UAS m.nilaiAkhir = (m.nilaiTugas * 0.30) + (m.nilaiUTS * 0.35) + (m.nilaiUAS * 0.35); m.grade = hitungGrade(m.nilaiAkhir);

Fitur Utama: Validasi input nilai, penyimpanan dinamis multi-data mahasiswa, dan cetak laporan tabel terformat rapi pada konsol terminal menggunakan library <iomanip>.

Aplikasi pemrosesan fungsi matematika f(x) = ax² + bx + c untuk menemukan nilai diskriminan, titik puncak ekstrim, arah kecekungan kurva, dan tabel domain.

Math & Computation

Fitur Utama: Menghubungkan teori matematika fungsi dengan pemodelan algoritma C++, serta menghasilkan pemetaan titik input/output domain secara otomatis.
